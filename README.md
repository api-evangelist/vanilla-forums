Vanilla Forums is the cloud community-forum platform now sold as Higher Logic Vanilla, powering B2B/B2C customer communities and association member communities. Every Vanilla community serves a REST API (API v2) at /api/v2 with a per-site OpenAPI 3 description, personal-access-token and JWT bearer authentication, short-lived cacheable role tokens, webhooks with HMAC-signed deliveries, CSV export, and an official MCP server (launched May 2026) that connects AI tools like ChatGPT, Claude, and Cursor to live community data. Originally a Techstars-backed open source project, Vanilla was acquired by Higher Logic in 2021.

**Areas:** Community · Forums · Community Management · Webhook · Customer Experience · Knowledge Base · Software-as-a-Service

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Vanilla Forums: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
